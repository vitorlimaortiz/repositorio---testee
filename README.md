##  Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade de extensão acadêmica, com o objetivo de praticar o controle de versão de arquivos utilizando Git e GitHub.

Durante a atividade, são explorados conceitos de criação de repositórios, documentação de projetos, edição de páginas HTML e registro de alterações por meio de commits.

##  Objetivos

- Aprender os conceitos básicos de Git e GitHub.
- Criar e organizar um repositório remoto e local.
- Documentar o projeto utilizando Markdown.
- Desenvolver uma página web simples com HTML.
- Registrar alterações utilizando Conventional Commits.
- Explorar o uso da Inteligência Artificial como apoio ao desenvolvimento.

##  Tecnologias e ferramentas

| Ferramenta | Finalidade |
|---|---|
| Git | Controle de versão |
| GitHub | Hospedagem do repositório |
| GitHub Desktop | Gerenciamento visual dos commits |
| Visual Studio Code | Edição dos arquivos |
| Live Server | Visualização da página no navegador |
| Inteligência Artificial | Apoio à análise de alterações e mensagens de commit |

##  Estrutura do projeto

```text
atividade-versionamento/
├── README.md
└── index.html
```

- `README.md`: documentação e informações do projeto.
- `index.html`: página web desenvolvida durante a atividade.

##  Fluxo de versionamento

1. Criação do repositório no GitHub.
2. Clonagem do repositório para o computador.
3. Edição dos arquivos no Visual Studio Code.
4. Visualização da página utilizando o Live Server.
5. Análise das alterações no GitHub Desktop.
6. Criação de commits com mensagens padronizadas.
7. Envio das alterações para o GitHub.

##  Conventional Commits

O padrão Conventional Commits organiza as mensagens de commit de acordo com o tipo de alteração realizada.

| Prefixo | Significado |
|---|---|
| `feat` | Nova funcionalidade |
| `fix` | Correção de erro |
| `docs` | Alteração na documentação |
| `style` | Ajustes de formatação |
| `refactor` | Reorganização do código |
| `test` | Alterações relacionadas a testes |
| `chore` | Tarefas de manutenção |

**Exemplo de commit:**

```text
feat: adiciona página inicial em HTML
```

##  Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Clique em **Go Live** para executar a página com o Live Server.

##  Aprendizados

A atividade permite compreender a importância do controle de versão, da documentação e do histórico de alterações no desenvolvimento de software.

Também demonstra como o GitHub facilita o armazenamento, a organização e o compartilhamento de projetos, enquanto ferramentas de Inteligência Artificial podem auxiliar na análise das modificações realizadas.
